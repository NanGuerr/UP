## 📈 1. Geometría Analítica y Álgebra Lineal

El contenido evalúa la capacidad de representar y resolver relaciones lineales y cuadráticas, así como sistemas de ecuaciones simultáneas. 📉

### 1.1. Ecuación de la Recta
Se abordan diversos métodos para determinar la ecuación de una recta ($y = mx + b$): 📉
*   **A partir de dos puntos:** Por ejemplo, la recta que pasa por $P_1(2,5)$ y $P_2(3,7)$ resulta en $y = 2x + 1$. 📍
*   **Punto y pendiente:** Dada una pendiente $m = 2$ y un punto $P_1(4,2)$, la ecuación se define como $y = 2x - 6$. 📐
*   **Pendiente y ordenada al origen:** Se presentan casos directos como $m = 2$ y $b = 3$, resultando en $y = 2x + 3$. 📏

### 1.2. Parábolas y Sistemas Lineales
*   **Parábolas:** Se requiere la graficación de funciones cuadráticas con diferentes concavidades y desplazamientos, tales como $y = 2x^2 + 3x - 2$ y $y = -3x^2 + 2x + 2$. 📈
*   **Sistemas de Ecuaciones:** Se resuelven sistemas de $2\times2$ mediante métodos algebraicos. Los resultados muestran soluciones con valores decimales precisos (ej. $x = 1,25$; $y = 0,875$ para el primer sistema propuesto). 🔣

## 🧮 2. Cálculo Diferencial

El análisis se divide en el cálculo de derivadas de una sola variable y el cálculo de la derivada total para funciones multivariables. 🔄

### 2.1. Derivadas de Funciones de una Variable
Se cubren diversas reglas de derivación: 📊
*   **Potencias y Polinomios:** Derivadas de $x^4$ ($4x^3$) y combinaciones como $2x^5 - 3x^2$ ($10x^4 - 6x$). ⚡
*   **Funciones Racionales:** Derivada de $1/x^5$ ($-5/x^6$). 📉
*   **Funciones Trigonométricas y Constantes:** Derivada de $x^3 + \sin x$ ($3x^2 + \cos x$) y de funciones con $\pi$ como $\pi x^2$ ($2\pi x$). 📐
*   **Regla del Cociente:** Aplicada en casos como $3x / \sin x$. ➗

### 2.2. Derivada Total
Se introduce el concepto de diferencial total para funciones con varias variables ($x, y, z$). Ejemplos clave incluyen: 🌐
*   Para $F = xy^2$: $dF = y^2 dx + 2xy dy$. 🔤
*   Para $F = xyz$: $dF = yz dx + xz dz + xy dz$. 📦
*   Para $F = x \cdot \sin y$: $dF = \sin y dx + x \cos y dy$. 🌊

## 📐 3. Trigonometría del Triángulo Rectángulo

El estudio de los triángulos rectángulos se centra en la resolución de lados y ángulos utilizando el Teorema de Pitágoras y funciones trigonométricas. 🔺

*   **Cálculo de Hipotenusa:** Para catetos de $3\text{ cm}$ y $5\text{ cm}$, la hipotenusa es $\approx 5,83\text{ cm}$. 📏
*   **Funciones Trigonométricas:** Se definen las seis funciones (seno, coseno, tangente, cosecante, secante y cotangente) para triángulos específicos. 📐
*   **Resolución de Lados y Ángulos:**
    *   Dada una hipotenusa $h = 6$ y un cateto $b = 4$, el lado $a$ resulta en $4,47$. 🔢
    *   Uso de ángulos: Con $b = 3\text{ cm}$ y $\theta = 30^\circ$, la hipotenusa $h$ es $6\text{ cm}$. 🧭

## ⚖️ 4. Magnitudes y Vectores

Este apartado clasifica las entidades físicas y detalla la operativa vectorial, fundamental para la física mecánica. 🚀

### 4.1. Clasificación de Magnitudes Físicas
El material establece una distinción clara entre magnitudes según su naturaleza: 📋

| Magnitud | Tipo | 🏷️ |
| :--- | :--- | :--- |
| **Masa** | Escalar | ⚖️ |
| **Temperatura** | Escalar | 🌡️ |
| **Tiempo** | Escalar | ⏱️ |
| **Energía** | Escalar | ⚡ |
| **Fuerza** | Vectorial | 🦾 |
| **Velocidad** | Vectorial | 🏎️ |

### 4.2. Operativa Vectorial
*   **Descomposición:** Se calculan componentes $A_x$ y $A_y$ usando el módulo y el ángulo ($\alpha$ con eje X o $\beta$ con eje Y). Por ejemplo, un vector de módulo $20$ a $30^\circ$ tiene componentes $A_y = 10$ y $A_x = 17,32$. ↗️
*   **Suma y Resta de Vectores:** Se realizan operaciones con notación de versores ($i, j$). El módulo de la resultante y su ángulo con el eje positivo $x$ son calculados (ej. resultante de $13,03$ con ángulo de $327,5^\circ$). ➕
*   **Producto Escalar:** ✖️
    *   Puede ser negativo si el ángulo entre vectores está entre $90^\circ$ y $180^\circ$. 📉
    *   Un producto escalar nulo no implica necesariamente vectores nulos; puede indicar que los vectores son perpendiculares ($90^\circ$). 📐
    *   Se utiliza para hallar el ángulo comprendido entre dos vectores mediante su definición analítica. 🔍
