# 📊 Guía de Conceptos: Probabilidad y Estadística

## 1. Clasificación de Datos Estadísticos

Los datos se categorizan según su naturaleza de la siguiente manera:

```txt

    Types of Data (Tipos de Datos)
├── Qualitative Data (Datos Cualitativos)
│   ├── Nominal Data
│   └── Ordinal Data
└── Quantitative Data (Datos Cuantitativos)
    ├── Discrete Data
    └── Continuous Data
```

## 2. Clasificación de Estudios Estadísticos

A continuación se detalla cómo se clasifican los estudios según diversos criterios metodológicos:

### 🎯 Según el objetivo

* **Exploratorio:** Se tiene poco conocimiento del problema; se plantea una hipótesis informal.
* **Confirmatorio:** Se posee información del problema; hipótesis explícita que se desea probar.
* **Correlación:** Se evalúa cómo se comporta una variable conociendo el comportamiento de otras.
* **Explicativo:** Trata de responder a las causas de los eventos.

### 🔬 Según intervención del investigador

* **Observacional:** Sólo se observa, no se interactúa (Ejemplo: encuestas).
* **Experimental:** Se aplican tratamientos analizando la respuesta.

### ⏳ Según el momento de recopilación

* **Longitudinal:** Se observa a un mismo grupo a lo largo de un tiempo.
* **Transversal:** Se observan a distintos grupos en un determinado momento.

### 🔢 Según el número de variables

* **Univariado:** Utiliza una sola variable.
* **Bivariado:** Utiliza dos variables.
* **Multivariado:** Utiliza más de dos variables.

### 📈 Según los métodos que utiliza

* **Descriptivo:** Recopila, caracteriza y presenta datos de una población o de una muestra con el fin de "describir" sus características.
* **Inferencial:** Estima características de una población o asiste en la toma de decisiones a partir de los valores observados en una muestra.
