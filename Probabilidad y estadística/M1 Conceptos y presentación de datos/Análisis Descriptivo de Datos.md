# 📊 Análisis Descriptivo de Datos

---

## 1. 📥 Recolección de Datos
El procedimiento de selección depende de listados existentes o construidos *ad hoc* (como cuestionarios).

* 📇 **Marcos de referencia comunes:** Directorios telefónicos, listas de asociaciones o escuelas oficiales.
* 📚 **Fuentes alternativas:** Cuando no existen listas, se recurre a hemerotecas, archivos o mapas.

> 💡 **Ejemplo Práctico:** En una investigación de mercado para una nueva red social, la población se definiría según el área geográfica de implementación y el cuestionario se diseñaría basado en la hipótesis de investigación.

---

## 2. 📝 Resumen e Informe
Para sintetizar la información se utilizan dos vías principales:

1. 🔢 **Métodos Numéricos:** Medidas descriptivas y métodos de inferencia estadística.
2. 📈 **Métodos Gráficos:** Representaciones visuales de los datos.

📄 **El informe estadístico** es el resultado final, donde se interpretan estos datos utilizando un lenguaje coloquial.

---

## 3. 📊 Tipos de Gráficos Estadísticos
El uso de gráficos permite una comparación rápida y clara. La elección depende del tipo de variable:

### A. 📊 Gráfico de Barras y de Bastones
Se utilizan para variables cualitativas o cuantitativas discretas.
* ➖ **Barras horizontales:** Ideales para variables cualitativas o geográficas.
* 📍 **Bastones:** Recomendados cuando existen numerosas categorías.

### B. 📉 Histograma
Representa variables cuantitativas continuas con datos agrupados en intervalos de clase. Permite visualizar frecuencias absolutas, relativas o porcentajes.

### C. 🍕 Diagrama Circular (o de Sectores)
Útil para describir la distribución de la población en porcentajes.
* ✅ **Ventaja:** Visualiza la importancia relativa de cada categoría.
* ⚠️ **Limitación:** No es recomendable si existen demasiadas categorías, ya que se pierde la claridad.

### D. 🎨 Pictogramas
Se utilizan figuras alusivas al tema de estudio en lugar de barras. Son comunes en variables cualitativas para hacer el dato más atractivo visualmente.

### E. 📈 Curvas de Frecuencias
* 📈 **Polígono de frecuencias (Gráfico de línea):** Útil para mostrar la evolución de un fenómeno en el tiempo o escalas críticas.
* 🔀 **Ojivas:** Específicas para leer o aproximar visualmente los percentiles.

---

## 4. 🗂️ Tabulación de Datos
Los datos pueden analizarse de forma simple o mediante tablas de contingencia (doble entrada).

### 📐 Nomenclatura Fundamental

| Sigla | Significado | Definición / Fórmula |
| :--- | :--- | :--- |
| **FA** | Frecuencia Absoluta | Número de repeticiones de la variable. |
| **FR** | Frecuencia Relativa | $FA / n$ |
| **FAA** | Frecuencia Absoluta Acumulada | Suma de frecuencias absolutas por renglón. |
| **FRA** | Frecuencia Relativa Acumulada | Suma de frecuencias relativas por renglón. |
| **%** | Porcentaje | $FR \times 100$ |

## 5. 🔍 Ejemplos de Interpretación

### 💬 Tabla de Serie Simple (Mensajes por día)
* 📌 **Dato:** 136 personas (35%) escriben 30 mensajes diarios.
* 📈 **Acumulado:** El 51% (199 personas) escribe 30 mensajes o menos.

### 🎂 Tabla de Intervalos de Clase (Edad)
* 📌 **Dato:** El 28% de la muestra (70 personas) tiene entre 14 y 16 años.
* 📈 **Acumulado:** 103 personas (41%) tienen menos de 16 años.

## 6. 🧠 Situación para Pensar: IA en la Universidad

🎓 **Estudio:** Evaluación del equilibrio emocional (escala 1-3) en usuarios de ChatGPT Edu vs. No usuarios.

📊 **Resultados del Análisis:**
1. 🤖 **Grupo IA-Chat:** El 40% presenta un nivel alto (valor 3).
2. ⚖️ **Comparativa:**
   * En el grupo "No-Chat", más del 20% tiene equilibrio bajo.
   * En el grupo "IA-Chat", la proporción de nivel alto es el doble que en el grupo de control.
3. 📐 **Métrica FRA:** Para el grupo No-Chat, la frecuencia relativa acumulada en el nivel medio ($x=2$) es de **0.80**.
4. 🏷️ **Clasificación de Variable:** El "equilibrio emocional" en este estudio se trata como una **variable cuantitativa discreta**.
