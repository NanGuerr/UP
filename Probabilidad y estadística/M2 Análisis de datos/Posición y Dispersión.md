# 📊 Resumen de Medidas Estadísticas

## 1. 📐 Medidas de Posición y sus Características

| Medidas de posición | Si los datos provienen de una variable cuantitativa | Si los datos provienen de una variable cualitativa | Si el grupo de datos tiene algunos valores muy distintos (outliers) |
| --- | --- | --- | --- |
| **Media** | Sí | No | No |
| **Mediana** | Sí | Sí, si está medida en escala ordinal | Sí |
| **Modo** | Sí | Sí | Sí |
| **Percentil** | Sí | Sí | Sí |

---

## 2. 🎯 ¿Cuál elegirías en cada caso? (Medidas de Posición)

| Caso / Situación | Medida elegida |
| --- | --- |
| Notas de un alumno en una materia | **Media** |
| Sueldos de empleados de una empresa (sindicato) | **Modo** |
| Sueldos de empleados de una empresa (patronal) | **Promedio** |
| Precios de un mismo artículo | **Promedio** |
| Estado civil de una persona | **Mediana o modo** |
| Nivel de satisfacción de un servicio | **Modo** |
| Litros de líquido que consume una persona a diario | **Promedio** |
| Medida de los tornillos de un lote, registrados por una persona en una planilla de cálculo | **Mediana** |
| Solo hay cupo para el 30% de los alumnos inscriptos, ¿a partir de qué nota ingresan? | **Percentil** |

---

## 3. 📉 ¿Qué medidas elegirías? (Medidas de Dispersión)

| Caso / Situación | Medida elegida |
| --- | --- |
| Nos interesa saber si la edad de los usuarios es pareja para vender publicidad para este sector en particular | **Coeficiente de variación** |
| Queremos saber entre qué edades se encuentra la mayoría de los usuarios | **Desvío estándar** |
| Queremos saber si el promedio del precio de un producto es representativo | **Coeficiente de variación** |
| Queremos comparar el rendimiento de grupos | **Desvío estándar** |
